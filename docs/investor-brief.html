01 · WHY NOW

The next user of scientific software is not a person

An agent can already read a paper, write code and call an API. What it cannot do is run a discovery workflow, because the software has no tool schema, no way to pay per call, and no way to prove afterwards which system produced a number. Whoever builds that surface first owns the layer the others plug into.

02 · WHAT IS BUILT

A workspace, and the machinery around it

Molecular workspace

Structures, pocket detection, docking, molecular dynamics, interaction analysis and library screening — in a browser or a headset.

Agent surface

22 typed tools. An MCP client lists them and drives a live session; verified end to end against a running browser.

Hands-free operation

Voice commands and WebXR hand tracking, so the workspace runs with no keyboard and no controllers.

Open data spine

Fourteen public databases. No account and no API key anywhere in the stack.

Agent economics

x402 payment challenges, NANDA discovery documents, OML-style fingerprints signing every result.

Provenance

A SHA-256 chain over every run. Alter one record and verification names it.

03 · WHAT IS NEWLY PROVEN

Thirty-three tests that run with no network

Added over the past two days, each verified by a command in the repository rather than asserted here.

33offline tests · node --test, pytest
22JavaScript · analysis and voice parsing
11Python · payment, discovery, signing

Two real defects were caught, and both would have reached a user. A flat limit on stored contacts was hiding the single aromatic-stacking record a chemist actually reads, while the counts stayed correct. And every spoken gene symbol ending in a digit silently failed to load, because a speech recogniser returns "lark two" for LRRK2 and letter-matching never got close. Neither shows up without tests, and neither would have been visible in a demo.

05 · WHY IT IS DEFENSIBLE

The hard part is not the viewer

Protocol surface

Tools, payment challenges, discovery documents and signatures are one registry. A competitor rebuilds a spine, not a feature.

Evidence discipline

Benchmarks published with failures, offline tests, provenance on every run. That is what a regulated buyer audits.

Disease focus

Sixty curated targets across ALS, Parkinson's and paediatric orthopaedics, verified against UniProt rather than scraped.

06 · WHO PAYS

Three buyers, three reasons

  • Disease foundations. A target and a grant, no computational team. They buy a workspace and a screen.
  • Pharma and biotech. An agent-operable workspace behind their own firewall, with an audit trail.
  • Agent platforms. They need a scientific tool their agents can call and pay for.
07 · HONEST LIMITS

What this is not, yet

  • Docking is triage, not prediction. Two of four, stated above.
  • Payments do not settle. The 402 challenge is real; the transfer is not implemented.
  • A hash chain is not a blockchain. It makes tampering detectable; it reaches no consensus.
  • Hand tracking is untested on hardware. Written to the WebXR spec and verified in code, not yet worn.
  • No revenue and no signed customer yet. This brief is about what is built and measured.
08 · THE ASK

Fund the scoring function

The benchmark is the ceiling on everything else we sell. Capital goes to the search and rescoring work that moves two of four toward the field standard, hardware testing on Quest and Vision Pro, and wiring payment settlement to a facilitator.
