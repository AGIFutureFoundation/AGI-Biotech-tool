The problem

Discovery software assumes a human is driving

A medicinal chemist moves between a structure viewer, a docking program, half a dozen database websites and a spreadsheet. Each hand-off loses context, and none of it records why a decision was made. Meanwhile the thing most likely to do that work next is an agent, and almost no scientific software can be called by one: there is no tool schema, no way to pay for a metered run, no way to prove afterwards which system produced a number.

For rare neurogenetic disease the gap is worse. The targets are poorly served, the data is scattered across public resources that each speak a different dialect, and the teams working on them are small.

The product

One workspace, three ways in

By hand

A 3D workspace in the browser or a headset. Pick up a protein, drop a compound in its pocket, pull it about while the physics runs. Pinch to grab, two pinches to scale, point to steer.

By voice

"Load LRRK2." "Find pockets." "Dock it." "What am I looking at?" The answer comes back spoken, which is what works on glasses with no display of their own.

By agent

Every panel action is a typed tool. An MCP client lists them and drives a live session — the same buttons a researcher presses, with the result read back.

Underneath: structures from the Protein Data Bank and AlphaFold, pocket detection, flexible docking, interaction fingerprints, library screening, molecular dynamics both interactive and all-atom, and a target evidence sweep across nine databases at once.

Architecture

Built so another agent can be the customer

Tool layer live

22 operations with JSON schemas. The same registry serves the console, the voice layer and the MCP server, so a new capability appears in all three at once.

x402 payments protocol only

Metered tools answer an unpaid call with a spec-shaped HTTP 402 challenge naming the price, asset and network. Settlement is deliberately not wired: no wallet, no funds move.

NANDA discovery live

A signed AgentFacts document at a well-known URL: identity, endpoints, capabilities, pricing, and the benchmark limits stated in the document itself.

OML-style fingerprints live

Secret challenge/response pairs prove which service answered, and every result carries a signature, so a figure can be checked long after the session ended.

Provenance chain live

Each run is appended to a SHA-256 hash chain. Alter one record and verification names it. A local chain, not a blockchain — nothing is broadcast.

Environments live

Any glTF scene becomes the backdrop: a lab, a city, a yacht. Exports arrive at any scale, so implausible ones are normalised and stood on the floor.

Honest limits

What this is not, yet

  • Docking is triage, not prediction. 2 of 4 re-docking cases within 2 Å. Treat scores as a ranking and run your own controls on targets you care about.
  • Interactive physics is coarse by design. Harmonic terms, an elastic-network backbone, no explicit water. The all-atom OpenMM backend is the one to quote.
  • Payments do not settle. The 402 challenge is real; the transfer is not implemented.
  • A hash chain is not a blockchain. It makes tampering detectable. It does not broadcast or reach consensus.
  • Ray-Ban Meta glasses cannot render this. No third-party WebXR browser exists for them. The voice companion on a paired phone is the honest substitute.
  • Hand tracking is untested on hardware. Written to the WebXR spec, verified in code, not yet worn.
